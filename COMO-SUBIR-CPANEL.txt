SIGAD · Cómo subirlo a cPanel con MySQL
========================================

Requisitos
- PHP 8.1 o superior (cPanel → MultiPHP Manager)
- Extensiones: pdo_mysql, mbstring
- MySQL o MariaDB (cPanel → MySQL Databases)

1. Crear la base de datos (una sola vez)
   cPanel → MySQL Databases
   - Base: sigad          → quedará como USUARIO_sigad
   - Usuario: sigad       → quedará como USUARIO_sigad
   - Asignar el usuario a la base con ALL PRIVILEGES
   Anote los tres datos: nombre BD, usuario y clave.
   El servidor es casi siempre: localhost
   Si ya la creó con install.php, no la vuelva a crear: vaya al paso 2.

2. Subir los archivos
   cPanel → Subdomains → document root de sigad.jeftech.net.pe
   Suba el ZIP sigad-cpanel.zip (no el botón Code de GitHub, no sigad_instalable).
   Extraer DENTRO de esa carpeta. Debe verse index.php, install.php, login.php
   junto a includes/, config/, db/, css/, assets/, uploads/.
   Si al extraer no se reemplazan los PHP, borre login.php e index.php y extraiga otra vez.
   El ZIP no pisa config.local.php (ahí quedan usuario y clave de MySQL).

3. Permisos
   Carpetas: 755
   uploads/ : 755 (escribible)
   config/  : 755 (escribible para que el instalador cree config.local.php)

4. Instalar o reparar conexión
   Abra https://sigad.jeftech.net.pe/install.php
   Complete localhost + los datos de MySQL.
   Si la base ya existe, el botón «Grabar conexión MySQL» no borra datos.
   Cuando el login funcione, ELIMINE install.php.

5. Tamaño de PDF (400 MB)
   cPanel → MultiPHP INI Editor:
     upload_max_filesize = 400M
     post_max_size       = 410M
     memory_limit        = 512M
   El archivo .user.ini ya trae esos valores; si no aplican, use el editor.

6. Entrar
   https://sigad.jeftech.net.pe/
   Usuario y clave los que puso en el instalador.
   El formulario correcto tiene los campos VACÍOS (no superadmin).

Si Chrome muestra HTTP ERROR 500 al pulsar Ingresar
- El servidor todavía tiene el login.php viejo. Siga el archivo 00-LEA-ESTO.txt.
- Después de extraer, abra /index.php: debe decir SIGAD-LOGIN-V2 en el HTML.
- Vuelva a ejecutar install.php para grabar la conexión (un ZIP viejo pisa config.php).

Si algo falla
- "Access denied": el usuario MySQL no está asignado a esa BD.
- "Unknown database": cree la BD en MySQL Databases; no intente crearla a mano.
- Aviso rojo de MySQL en el login (ya no 500): install.php con los datos de cPanel.
- No sube el PDF: suba upload_max_filesize en MultiPHP INI Editor.
